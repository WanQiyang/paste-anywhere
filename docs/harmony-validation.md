- 编译 SDK 为 API 26；原型暂设兼容 API 12（HarmonyOS 5.0.0），这是待真机确认的候选下限，不代表已验证 API 12 兼容性。

## 构建与签名

1. 用 DevEco Studio 打开仓库的 `clients/harmony` 目录，完成工程同步。
2. 通过 USB 连接手机，启用开发者模式与 USB 调试，并在手机上允许电脑调试。
3. 检查设备连接（默认安装路径）：

   ```powershell
   & 'C:\Program Files\Huawei\DevEco Studio\sdk\default\openharmony\toolchains\hdc.exe' list targets
   ```

4. 在 DevEco 的项目签名设置中登录开发者账号，为当前设备配置调试签名。具体入口以当前 IDE 为准。
5. 选择手机运行 `entry`。本机已配置签名；新环境仍需配置，unsigned HAP 不能直接安装到普通真机。

构建命令（仓库根目录，是否签名取决于本机配置）：

```powershell
pwsh -NoProfile -File scripts/build-harmony.ps1
```

默认产物目录：`clients/harmony/entry/build/default/outputs/default/`。

签名证书、Profile 和密码仅保存在本机。IDE 可能将本机签名配置写入 `build-profile.json5`，提交前检查差异，不提交该部分；仓库中的 `signingConfigs` 保持空数组。`.gitignore` 已忽略常见签名文件及构建产物。

提交整理时已将本机完整签名工程配置备份为 `clients/harmony/build-profile.local.json5`（被 Git 忽略）。此文件不会自动加载；需要本机签名时可在 IDE 重新配置，或将备份中的签名部分合入 `build-profile.json5`，提交前再次移除。无签名配置的干净检出只能构建 unsigned HAP。

## 真机验收表

按上述反馈继续补齐验证。记录手机型号、系统/API 版本、来源/目标 App 名称及版本；失败时记录页面状态或日志错误码。

| 场景 | 预期 |
| --- | --- |
| 冷启动接收文本 | 从其他 App 分享文字后出现本应用，打开显示完整文字 |
| 热启动接收文本 | 应用已打开时再次分享，当前卡片被新文本替换 |
| 单图分享 | 从相册选单图分享，显示图片；临时 URI 已复制到应用缓存 |
| 图片再次取用 | 切换来源 App、返回本应用后仍可显示与转发缓存图片 |
| 手动复制文本 | 点击复制后，其他 App 普通粘贴可得到原文，含中文/换行 |
| 手动复制图片 | 点击复制后，支持图片粘贴的目标 App 可粘贴图片 |
| 文本/图片转发 | 点击分享出现系统面板，目标 App 获得正确内容 |
| 不主动写剪贴板 | 打开、接收分享、转发不会修改系统剪贴板；只有复制按钮会写入 |
| 多图或不支持类型 | 不应作为支持的输入；若系统仍发来多条，页面明确拒绝 |
| 连续分享 | 旧分享的异步处理不能覆盖较新的分享 |

图片保存在应用缓存目录；当前已有 16 MiB / 4000 万像素限制及缓存清理，具体格式与保留规则见协议文档。
