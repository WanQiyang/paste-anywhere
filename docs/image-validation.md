# 图片双向联调

沿用已经验证的地址、账号和端口转发，无需重新获取邀请码。

## 更新

- 服务端需要运行当前图片版可执行文件（新增图片路由和附件表）。
- 鸿蒙安装当前签名 HAP，连接设置保留。
- Windows **先右键旧版托盘图标 → 退出**，再从仓库根目录启动新版：

  ```powershell
  dotnet run --configuration Release --no-build --project clients/windows/PasteAnywhere/PasteAnywhere.csproj
  ```

  未构建时先执行 `dotnet build clients/windows/PasteAnywhere.sln --configuration Release`。

## 手机 → Windows

1. 手机相册选单张图片，系统分享给 Paste Anywhere。
2. 页面应显示上传成功，并可预览远程图片。
3. Windows 在线时自动下载并更新系统剪贴板。
4. 在画图等支持图片的应用中按 `Ctrl+V`；也可打开 Windows 客户端查看预览。

先用普通截图 PNG 或 JPEG 照片验证，再测试 HEIC 等需要转换的格式。

## Windows → 手机

1. 用截图工具将图片放进剪贴板，或在画图中选中区域按普通 `Ctrl+C`，再按 `Ctrl+Alt+C` 发送。
2. 或在资源管理器中先复制**单个 PNG/JPG 文件**，再按同一发送快捷键。
3. 手机保持客户端前台，应自动显示收到的图片。
4. 点击“分享到其他应用”，确认目标 App 收到图片。

快捷键直接发送当前剪贴板，不模拟复制、不要求内容刚发生变化。可以发送截图工具之前写入的图片；发送本身不修改本地剪贴板。

## 其他验收

- 图片与文本交替上传，预览和系统剪贴板正确切换。
- 大图下载期间收到较新文本/图片，旧下载不得覆盖新内容。
- 历史列表能打开图片，拖动当前图片给其他用户后，对方收到新条目。
- Windows 重连不主动替换剪贴板；手机后台不接收，返回前台获取最新。
- 超过 16 MiB 或 4000 万像素时明确报错，旧远程条目保持不变。
- 手机图片复制仍标注兼容性待验证，优先使用系统分享。接口写入成功不等于微信/QQ支持图片粘贴。

## 已自动验证 / 待真机验证

服务端测试覆盖 PNG/JPEG 上传、二进制往返、通知、跨用户转发复用文件、下载隔离、无效/截断/超限输入、引用清理、失败回滚及旧文本数据库升级。

用户已确认双向图片联调没有问题，且 Windows 快捷键改为“发送当前剪贴板”后的交互正确；其他边界场景仍需按上表逐项确认。
