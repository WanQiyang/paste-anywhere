# 当前版本验收清单

环境搭建见 [开发指南](development.md)，公网部署见 [部署说明](deployment.md)。以下为检查项，不表示已通过；记录实际源码版本、设备/系统、来源与目标应用及错误日志。

## 服务与管理

- 新建数据库、创建/列出/删除用户和设备；重启后账号、内容及凭证持久化。
- `user reset` 返回新码，删除该用户全部设备，保留用户及内容；旧码/凭证失效，其他用户不受影响，原设备名可重新配对。
- 表格列、名称排序、在线设备去重、创建/配对/活跃/内容时间、平台、版本、代理后 IP 正确；服务不可用时在线状态为“未知”。
- `DISPLAY_TIMEZONE` 的默认 +8、负偏移、半小时时区与夏令时显示正确。
- VPS 域名、证书、HTTP/WebSocket、容器重启及备份恢复；拒绝非当前格式数据库。

## 配对与界面

- 配对字段及错误文案、请求时禁用、非法响应不保存凭证；重复设备名被拒绝。
- 未连接时隐藏在线数量及括号，ready 且取得数量后显示；同设备多连接计一次，自己始终首位，其他离线用户移除。
- “在线剪贴板”固定 5 卡片及占位，短屏完整显示；底部版本与包版本一致。
- 登出和红色“清空”均需确认；取消无副作用；离线/操作中正确禁用按钮，空列表禁止清空。
- 登出释放设备名；网络失败保留配置，已撤销凭证可本机登出并重新配对。

## 读取、同步与转发

- “手动复制”上传当前系统剪贴板快照，支持纯文本、单图，空内容/不支持类型有反馈。读取后再次复制不替换正在上传的内容。
- Windows 快捷键与按钮行为一致；普通复制不上传。鸿蒙首次授权、拒绝授权及再次尝试均可处理。
- 两方向检查中文、换行、完整 URL、PNG/JPEG、其他可解码图片；验证 16 MiB / 4000 万像素限制。
- Windows 在线新通知自动写剪贴板，启动/重连不写；鸿蒙仅前台接收，卡片复制/分享按用户选择执行。图片粘贴及系统分享在实际目标应用验证。
- 上传失败可重试当前内容；新分享读取失败不重试上一条内容，冷/热启动连续分享不被晚到结果覆盖。
- 同账号多设备同步；跨用户普通上传保持隔离，拖动任意卡片发送至对方或自己，接收者保留历史，发送者不被反向覆盖。
- Windows 短按复制、长按浮起、高亮、边缘滚动、松手/Esc 清理；鸿蒙原生长按拖动、目标选择正确。
- 清空通知所有本账号设备，不改系统剪贴板及其他用户副本；晚到下载不回填，清空后的新内容保留。
- 大图下载期间收到更新，不覆盖较新内容；来源设备不接收自身回写；鸿蒙前后台切换及图片缓存再次分享、清理正确。

## Windows 托盘与自启

- 关闭隐藏、双击打开、菜单退出；快捷键冲突有提示。
- 自启默认关闭，启用后注销/登录只显示托盘；移动程序目录后重新保存自启设置生效。
