# 当前版本验收清单

自动检查和环境搭建见 [开发指南](development.md)。以下用于人工验证平台交互；记录版本、设备、来源/目标应用及实际结果。

## 服务与管理

- 在实际部署环境验证 HTTPS/WebSocket、容器重启与数据库/附件联合备份恢复。
- CLI 显示平台、版本、代理后 IP、时区和在线状态；重置配对码或撤销设备后，已有连接按协议失效。

## 配对与界面

- 配对字段、错误提示及请求时禁用；重复设备名被拒绝，网络失败不丢失本机配置。
- 未连接时隐藏在线数量及括号，ready 且取得数量后显示；同设备多连接计一次，自己始终首位，其他离线用户移除。
- “在线剪贴板”固定 5 卡片及占位，短屏完整显示；底部版本与包版本一致。
- 登出/清空确认文案与基线一致，取消无副作用；上传期间禁用，空列表不能清空。Windows 默认焦点在取消，支持 ×、Esc。
- 登出释放设备名；网络失败保留配置，已撤销凭证可本机登出并重新配对。

## 读取、同步与转发

- “粘贴”上传一次快照，后续复制不替换正在上传的内容；空内容/不支持类型有反馈，离线或操作中禁用。Windows 快捷键行为一致；鸿蒙授权失败不读取。
- 双向验证中文、换行、URL、截图、带透明度 PNG、相册 JPEG/HEIC 及文件分享；覆盖 16 MiB / 4000 万像素边界。Windows 同时存在 PNG 和 DIB 时使用原始 PNG。
- Windows 默认对在线更新自动写剪贴板，启动/重连不写；开关行为见下节。鸿蒙仅前台接收，卡片复制/分享按用户选择执行。图片粘贴及系统分享在实际目标应用验证。
- 上传失败后重新粘贴或分享；冷/热启动连续分享不被晚到结果覆盖，新分享失败不发送旧内容。
- 同账号多设备同步；跨用户普通上传保持隔离，拖动任意卡片发送至对方或自己，接收者保留历史，发送者不被反向覆盖。
- 预览长文本可滚动，横/竖/大/小图片等比完整显示，短屏操作可见；列表刷新不改变所选条目，关闭后晚到结果不影响新弹窗。
- 慢网预览显示真实字节进度，超时/失败可重新下载；重复预览、复制/分享复用缓存。清空后旧条目操作失败，正在预览或上传的文件不被缓存清理删除。
- Windows 点击及 200–400ms 慢点击打开预览；500ms 长按或明显移动才拖拽。验证目标高亮、边缘滚动、松手/Esc/捕获丢失清理；鸿蒙验证原生长按拖放。
- 预览本身不写剪贴板；复制成功提示“已复制”并关闭，失败可重试，连续点击不重复执行。Windows 关闭、×、Esc 均有效；鸿蒙分享可在实际目标应用使用。
- 清空通知所有本账号设备，不改系统剪贴板及其他用户副本；晚到下载不回填，清空后的新内容保留。
- 大图下载期间收到更新，不覆盖较新内容；来源设备不接收自身回写；鸿蒙前后台切换及图片缓存再次分享、清理正确。

## Windows 托盘与自启

- 关闭隐藏、双击打开、菜单退出；快捷键冲突有提示。
- 自启默认关闭，启用后注销/登录只显示托盘；移动程序目录后重新保存自启设置生效。
- 设置显示“快捷键：将系统剪贴板上传”“开机时自动启动”，所有选项无小字注释；三个新增开关默认选中，保存后重启、登出再配对仍保留，未配对也能保存。
- 关闭“自动覆盖系统剪贴板”后，文本/图片更新仍进入在线列表，但不写系统剪贴板、不为自动写入下载图片；手动预览复制仍有效。下载或剪贴板占用重试期间关闭再开启开关，旧任务完成后不写入；重新开启不回放历史。
- “粘贴”和快捷键上传成功均按“上传在线剪贴板成功时通知”显示 Windows 原生通知；自动接收和预览复制成功均按“系统剪贴板被覆盖时通知”显示原生通知。开关独立生效，隐藏到托盘时也可通知，失败/过期结果不发成功通知；实际显示遵循 Windows 通知及勿扰设置。
