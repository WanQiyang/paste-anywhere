# Windows 便携版

完整解压 ZIP 后启动 `PasteAnywhere.exe`。`standalone` 包自带运行时，无需安装 .NET；`framework-dependent` 包需要安装 .NET 10 Windows Desktop Runtime。

首次填写服务器 HTTPS 地址、设备名和用户专属邀请码。同一用户的设备使用同一个邀请码，不同用户使用不同邀请码。

- 先普通复制或截图，再按 `Ctrl+Win+Alt+C` **发送当前系统剪贴板**；右键托盘图标选择“设置”可更改发送快捷键。
- “粘贴”与快捷键相同，读取当前系统剪贴板并上传到本账号在线剪贴板。
- 在线收到新内容自动写系统剪贴板，使用普通 `Ctrl+V` 粘贴。
- 启动或重连不会自动覆盖系统剪贴板；GUI 自动展示最近 5 条，点击卡片预览并选择复制。图片卡片显示 `<图片>`。
- 在线用户横向排列，自己置顶，其余按用户名排序；拖动任意一条内容到用户卡片即可发送，包括发给自己。账号旁绿灯表示实时连接已建立，红灯表示未连接。
- 右上角登出经确认后撤销当前设备并清除本机配对信息，之后可用同一设备名重新配对。
- 连接成功且数量已知时，账号旁显示“x 台在线”；离线时隐藏整个括号。红色“清空”经确认后删除当前账号全部在线内容并同步到各设备，不清除本机系统剪贴板。
- 关闭窗口后仍驻留托盘。右键托盘图标选择“退出”可完全退出。
- 右键托盘 → “设置”可勾选“开机自启”并保存，默认关闭。Windows 登录时自动启动到托盘，不弹主窗口；双击托盘图标打开。该选项仅作用于当前 Windows 用户，不需要管理员权限。移动程序目录后，在新位置重新保存设置以更新启动路径。

只运行一份客户端，避免争抢快捷键。账号配置通过 Windows DPAPI 保存在当前用户的 `%LOCALAPPDATA%\PasteAnywhere\connection.bin`，不要复制给其他人。

当前支持文本和单张图片，客户端图片上限为 16 MiB / 4000 万像素。此便携包尚未进行 Windows 代码签名。
