# Windows 便携版

完整解压 ZIP 后启动 `PasteAnywhere.exe`。`standalone` 包自带运行时，无需安装 .NET；`framework-dependent` 包需要安装 .NET 10 Windows Desktop Runtime。

首次填写服务器 HTTPS 地址、设备名和用户专属配对码。同一用户可重复使用配对码，设备名不能重复。

- 普通复制或截图后，按 `Ctrl+Win+Alt+C` 或点击“粘贴”，将当前系统剪贴板上传到本账号在线剪贴板。
- 默认在线收到新内容自动写系统剪贴板，随后可用 `Ctrl+V` 粘贴；启动或重连不覆盖。界面展示最近 5 条，点击卡片预览并复制，图片卡片显示 `<图片>`。
- 在线用户横向排列，自己置顶，其余按用户名排序；拖动任意一条内容到用户卡片即可发送，包括发给自己。账号旁绿灯表示实时连接已建立，红灯表示未连接。
- 右上角登出经确认后撤销当前设备并清除本机配对信息，之后可用同一设备名重新配对。
- 连接成功且数量已知时，账号旁显示“x 台在线”；离线时隐藏整个括号。红色“清空”经确认后删除当前账号全部在线内容并同步到各设备，不清除本机系统剪贴板。
- 关闭窗口后仍驻留托盘。右键托盘图标选择“退出”可完全退出。

## 设置

右键托盘图标 → “设置”，修改后点击“保存”：

- “快捷键：将系统剪贴板上传”：默认 `Ctrl+Win+Alt+C`。
- “开机时自动启动”：默认关闭，仅作用于当前 Windows 用户。登录后启动到托盘，双击图标打开；移动程序目录后需重新保存以更新启动路径。
- “自动覆盖系统剪贴板”：默认开启；关闭后仍更新在线列表，可手动预览复制。
- “上传在线剪贴板成功时通知”“系统剪贴板被覆盖时通知”：默认开启，分别控制上传成功和应用写入剪贴板成功的原生通知，显示遵循 Windows 通知及勿扰设置。

只运行一份客户端，避免争抢快捷键。账号配置通过 Windows DPAPI 保存在 `%LOCALAPPDATA%\PasteAnywhere\connection.bin`，不要复制给其他人。三个开关保存在同目录的 `preferences.json`，未配对时也可设置，登出后保留。

当前支持文本和单张图片，客户端图片上限为 16 MiB / 4000 万像素。此便携包尚未进行 Windows 代码签名。
